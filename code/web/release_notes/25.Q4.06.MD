# Quarterly Hotfix 6

---

## Aspen Discovery Updates

### Cover Images Updates
- Add support for ChiliFresh as a cover image source. ([DIS-1602](https://aspen-discovery.atlassian.net/browse/DIS-1602)) (*GMC*)

### Loral for Libraries Integration
- Allow integration with new Loral Content Enrichment service supported by Grove for Libraries. (DIS-1686) (*MDN*) 
  - Display Covers from Loral
  - Display Descriptions from Loral
  - Display Review Quotes from Loral
  - Display Author Biographies from Loral

### New York Times Updates
- Allow New York Times API Keys to be 48 characters rather than 32. (DIS-1702) (*MDN*)
- Connect to the New York Times API using https rather than http. (DIS-1703) (*MDN*)

## New Settings
- New External Request Settings to enable logging by request type (DIS-1485) (*IT*)

### System Maintenance
- Add a tool to allow reading history entries to be consolidated. (DIS-179) (*MDN*)
  - Can either run one barcode at a time or can process all barcodes. 
  - Process runs as a background process.
