# Quarterly Hotfix 4

---

***The following notes include hotfix changes that were released on 11/14/25. These are typically bug fixes discovered in the base 25.Q4.00 release.***

## Aspen Discovery Updates

### API Updates
- Updated `getPatronProfile()` under the UserAPI to return `hideSoftDeleteListUI`. (DIS-1584) (*LS*)

### Cover Images Updates
- Fixed an issue where uploaded cover images for referenced grouped works were ignored when "Use Original Cover URLs" was enabled. (DIS-1446) (*LS*)

### User Lists Updates
- Fixed an issue where lists could not be deleted from LiDA. (DIS-1584) (*LS*)
- Fixed Publication Date sorting where items with valid publication dates were incorrectly appearing at the end of the list. (DIS-1591) (*LS*)
- Fixed Call Number sorting where items with empty call numbers were incorrectly appearing at the top of the list. (DIS-1591) (*LS*)

### Other Updates
- Corrected pagination issue when filtering on the Restore Deleted Objects page. (DIS-1584) (*LS*)
- Resolved an issue where uploaded images and files would not be permanently deleted after 30 days of being soft-deleted. (DIS-1584) (*LS*)
- Fixed duplicate series display in record details and search results by removing redundant `$indexedSeries` variable because `getSeries()` now populates `additionalSeries` with indexed series data. (DIS-1518) (*LS*)
- Increased the HTTP stream timeout when updating suggesters in Solr. (DIS-1592) (*LS*)
- Added a "Clear Cached Values" button under System Variables for admins to purge cached values manually. (DIS-1531) (*YL*)
 - The cache is cleared after every Aspen upgrade. (DIS-1531) (*YL*)
