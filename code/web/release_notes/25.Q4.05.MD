# Quarterly Hotfix 5

---

***The following notes include hotfix changes that were released on XX/XX/25. These are typically bug fixes discovered in the base 25.Q4.00 release.***

## Aspen Discovery Updates

### Events Updates
- Focused the Springshare LibCal orphan cleanup so it only runs when at least one LibCal setting exists or when orphaned events still need removal after settings were deleted. (DIS-1546) (*LS*)

### Koha Updates
- Removed automatic insertion of default 9-5 library hours when no hours exist in the Location settings. (DIS-1604) (*LS*)

### Materials Requests Updates
- Fixed date filter in Manage Materials Requests to make the "To" date inclusive of the entire day, resolving issues where requests made on the current day were excluded from filter results. (DIS-1486) (*LS*)

### OverDrive Updates
- Fixed OverDrive availability counts showing double the actual number of copies and holds when libraries had access to both library-specific and shared collection records for the same title. (DIS-1606) (*LS*)

### Polaris Updates
- Fixed an issue where self registration required a hardcoded minimum age of 13 years; instead, it will use the "Minimum Age" field in Library System settings. (DIS-1621) (*LS*)

### Other Updates
- Included ISBN and UPC data in the CSV export of search results. (DIS-1379) (*LS*)
- Fixed fatal error on Manage Requests page when displaying requests created by users without ILS barcodes. (DIS-1594) (*LS*)
- Fixed an issue where browser refreshes after self-registration could create duplicate patron accounts. (DIS-1611) (*LS*)
