The goal of this project is for ByWater staff to rewrite the Overdrive Extractor in Kotlin.

None of us is super familiar with Kotlin, but it'll be a good learning experience for all, and it's similar enough to most other Object-Oriented languages that it should be fairly simple to pickup.  

In terms of contributing, I think we should use *overdrive_kotlin* as the main branch, then create PRs into it so that we all have a chance to review each other's code.
